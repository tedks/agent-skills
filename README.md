# Agent skills — archived

Active development and fleet installation have moved to [tedks/orgs](https://github.com/tedks/orgs). The skills now live in [`orgs/skills/`](https://github.com/tedks/orgs/tree/master/skills), and the agent tooling and harness bindings live in that repository alongside them.

This repository remains available as the historical source. Its commits were merged into orgs with their ancestry intact. The former installation instructions here are superseded by the [orgs README](https://github.com/tedks/orgs#readme) and the current [dotfiles installer](https://github.com/tedks/dotfiles/blob/master/docs/agent-skills-install.md).
